How saving works

  • Every time you press Save or confirm a scan, the change is written straight into the database file above.
  • The file always stays on the computer (or PythonAnywhere account) that runs the site, even when you use the site from your phone.
  • Download Excel copy builds a fresh .xlsx from the current data and sends it to the device you are using. The copy does not update later, so download again for the latest.
  • Automatic backups of the database are kept in the backups folder next to it.
  • An older attendance_records.xlsx is imported once, the first time the site starts without a database. It is never changed afterwards.
  • The changes log is a separate file in the same folder: {{ log_name }}.
