How saving works

  • Every time you press Save to Excel or confirm a scan, the change is written straight into the file above.
  • The file always stays on the computer that runs start.bat, even when you use the site from your phone.
  • Download a copy sends a copy to the device you are using now. From a phone it goes to the phone's Downloads. The copy does not update later, so download again for the latest.
  • If Excel has the file open, saving from the website is blocked until you close Excel.
  • To move the file, stop the site, move attendance_records.xlsx to another folder, then edit XLSX near the top of app.py.
  • The changes log is a separate file in the same folder: {{ log_name }}.
